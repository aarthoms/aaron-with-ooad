# GRASP: **General Responsibility Assignment Software Patterns**

There are 9 patterns & principles in GRASP
1. Controller -- An object that handles a system event and delegates to other objects. Entry-point facade
2. Creator -- Classes create what they contain 
3. Information Expert -- Each class handles it's own data 
4. Low Coupling -- Reduce inter-dependency between classes. Independence b/w classes
5. High Cohesion -- A Class should have a narrow, focused set of responsibilities.
6. Polymorphism  -- Use of Polymorphism to reduce coupling between types and variants.
7. Protected Variation -- Shield stable interfaces from points of likely change
8. Indirection  -- Use a middleman object to avoid coupling between two classes
9. Pure Fabrication -- Invent a class that has a no real-world counterpart, purely for cohesioin.
